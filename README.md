# 🎓 동서대학교 통합 캠퍼스 플랫폼 (PWA)

동서대학교 학생들을 위한 올인원 모바일 웹 / PWA 어플리케이션입니다.  
공식 홈페이지를 번거롭게 방문하지 않고도 **공지사항(인앱 네이티브 뷰어)**, **주요 학사일정(D-Day)**, **오늘의 학식 식단 및 재학생 인증 한줄평**을 한눈에 확인할 수 있습니다.

---

## 📱 주요 핵심 기능

1. **📢 공지사항 인앱(In-App) 네이티브 뷰어**
   - 일반, 학사, 장학, 취업, 행사 등 카테고리 탭 분류
   - 공식 홈페이지를 새 창으로 열 필요 없이 **앱 안에서 즉시 본문, 이미지, 표 확인**
   - 첨부파일 목록 확인 및 다이렉트 다운로드
   - 실시간 제목/본문 키워드 검색 및 스크랩(북마크) 보관함 기능

2. **🍽️ 교내 식당별 학식 메뉴 & 재학생 리뷰**
   - 학생식당, 교직원식당, 기숙사식당 식단 탭 제공
   - 코너별(일품, 백반, 석식 등) 메뉴 및 가격/칼로리 표시
   - **동서대 공식 웹메일(`@dongseo.ac.kr`) 인증** 기반 별점 및 한줄평 커뮤니티 (학번/아이디 자동 마스킹 보호)

3. **📅 학사일정 캘린더 & D-Day**
   - 수강신청, 정정기간, 중간/기말고사, 대동제 축제 등 중요 학사일정 D-Day 카운트다운
   - 월별/카테고리별 일정 타임라인

4. **🚀 모바일 웹 & PWA (홈 화면 바로가기)**
   - 스마트폰(Safari/Chrome)에서 '홈 화면에 추가' 시 네이티브 앱처럼 전체화면 구동

---

## 🛠️ 기술 스택

- **프레임워크**: Next.js 14 (App Router) + TypeScript
- **스타일링**: Tailwind CSS (동서대 시그니처 크림슨 레드 `#9e1b32` 컬러셋 적용)
- **아이콘**: Lucide React
- **데이터 파싱/크롤러**: Cheerio (동서대 홈페이지 HTML 파서 + 안정적인 고품질 Mock Fallback)
- **데이터베이스/인증**: Supabase (PostgreSQL) + 로컬 자동 폴백 스토리지 지원

## 💻 실행 방법

### 1. 패키지 설치
```bash
cd C:\Users\wnsh3\.gemini\antigravity\scratch\dongseo-campus-app
npm install
```

### 2. 로컬 개발 서버 실행
```bash
npm run dev
```

브라우저에서 `http://localhost:3000` 접속 후 모바일 뷰(F12 > 모바일 디바이스 툴바) 또는 스마트폰으로 접속하시면 최적화된 화면을 확인하실 수 있습니다.
